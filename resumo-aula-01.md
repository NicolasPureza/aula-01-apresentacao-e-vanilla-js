# Resumo da Aula 01 — Apresentação da Disciplina e Contextualização

## 1. Contexto da Disciplina
Atualmente, grande parte das aplicações Web modernas utiliza **Frameworks Front-end** para entregar interfaces rápidas, organizadas, escaláveis e fáceis de manter. O domínio dessas ferramentas é um requisito estratégico no mercado de desenvolvimento de software.

---

## 2. O que é Desenvolvimento Front-end?
O **Front-end** é a camada da aplicação com a qual o usuário interage diretamente no navegador. Suas principais responsabilidades incluem:
- Construção da interface visual e organização dos elementos na tela;
- Experiência do usuário (**UX**) e design de interface (**UI**);
- Interatividade no cliente e comunicação com sistemas de Back-end (APIs) responsáveis pelo processamento e persistência dos dados.

---

## 3. Arquitetura de um Site
Antes de escrever código, o desenvolvimento de um projeto Web passa pela definição de arquitetura:
- **Definição de escopo, prototipação e UX:** mapear necessidades, fluxos de navegação e telas antes da implementação;
- **Importância de UX/UI:** garantir clareza, usabilidade e acessibilidade;
- **Validação e iteração:** testar protótipos e refinar funcionalidades com ferramentas adequadas.

---

## 4. Introdução ao Versionamento e Deploy
- **Versionamento (Git e GitHub):** permite registrar o histórico de alterações do código, trabalhar em equipe sem sobrescrever arquivos e recuperar versões anteriores com segurança.
- **Deploy (Vercel):** processo de publicação da aplicação em produção por meio de uma URL pública, integrando diretamente o repositório do GitHub para atualizações automáticas.

---

## 5. Introdução ao JavaScript (Vanilla JS)
- **O que é:** linguagem de script interpretada executada no navegador, essencial para o desenvolvimento Front-end.
- **Vanilla JS:** refere-se ao uso de JavaScript puro, sem bibliotecas ou frameworks externos, servindo como base para todas as abstrações modernas.
- **Importância:** permite manipular o DOM, responder a eventos do usuário, validar formulários e se comunicar com servidores.

---

## 6. Introdução a Frameworks Front-end
- **Principais ferramentas:** React (biblioteca focada em UI), Vue.js e Angular.
- **Arquitetura e Componentização:** divisão da interface em componentes independentes e reutilizáveis.
- **Estado, Rotas e Dados:** gerenciamento de estado da aplicação, navegação entre telas (SPA) e integração com APIs.

---

## 7. Objetivos da Disciplina e Avaliação
Ao final do semestre, espera-se que o estudante seja capaz de:
1. Desenvolver interfaces modernas e responsivas;
2. Criar aplicações utilizando Frameworks Front-end e Frameworks CSS;
3. Versionar projetos com Git e GitHub;
4. Publicar aplicações na Web (Vercel / Render).

### Critérios de Avaliação Apresentados
- **55% — Avaliação Docente:** 20% Desenvolvimento de Projeto ("mini TCC") + 20% Apresentação do Projeto + 15% Realização das atividades;
- **35% — Projeto Integrador;**
- **10% — Autoavaliação.**
